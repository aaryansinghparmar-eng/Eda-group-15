# Cricket Player Performance Analysis

**Exploratory Data Analysis (EDA) Project**
**Group 15 | F.Y. BCA – Semester I**

## About

This project is an Exploratory Data Analysis of a cricket player statistics dataset containing **119 players and 16 variables**.

We looked at different batting statistics to understand player performance, find interesting patterns, and compare players using data and visualizations.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## What We Analyzed

* Data Cleaning
* Descriptive Statistics
* Univariate Analysis
* Bivariate Analysis
* Correlation
* Data Visualization

## Key Findings

| Statistic           | Player           | Result |
| ------------------- | ---------------- | -----: |
| Highest Runs        | SR Tendulkar     | 18,426 |
| Highest Average     | RN ten Doeschate |  67.00 |
| Most Centuries      | SR Tendulkar     |     49 |
| Highest Strike Rate | JC Buttler       | 118.66 |

## Conclusion

Through this project, we used EDA techniques to get a better understanding of cricket player performance. The analysis helped us compare different batting statistics and identify some of the strongest performances in the dataset.

All findings are based on the supplied dataset.
